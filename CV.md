# CV description

**Cost-Sensitive Credit Card Fraud Detection | Python, pandas, scikit-learn**

- Built a reproducible fraud detection pipeline on 284,807 public credit card transactions, comparing logistic regression and histogram gradient boosting with chronological splits, engineered features and validation-based cost-sensitive thresholds.
- Achieved 0.788 average precision, 86.4% precision and 74.0% recall on a 60,140-transaction chronological test set using gradient boosting; verified the project with 12 automated tests and saved-model prediction checks.
